One-line elevator pitch (153 characters) a city pigeon gives investors for its startup:

> We outlived the dinosaurs, the Romans, and your last three startups — invest in the only unicorn that's actually a bird. We never pivot, we just migrate.

The line is the whole entry. `main.py` prints it, validates the 1–200 character gate, and writes it to `entry.txt`.

## Run it

```sh
python3 main.py
```
